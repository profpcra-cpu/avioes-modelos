# ✈️ Airplane Builder 3D

PWA de montagem de aviões em 3D. Arraste peças até o encaixe correto.

## Como jogar

1. Escolha um avião no menu
2. Arraste as peças até os contornos pontilhados
3. Complete todas para desbloquear o próximo

## Instalar como app

- **Android/Chrome**: toque no ícone ⬇️ na navbar ou no menu ⋮ → "Instalar app"
- **iOS/Safari**: Compartilhar → "Adicionar à Tela de Início"
- **Desktop**: ícone ⊕ na barra de endereço do Chrome/Edge

## Recursos

- ✅ 4 aviões (papel, caça, biplano, jato)
- ✅ Arrastar peças com mouse/toque
- ✅ Câmera orbital 3D
- ✅ Som sintetizado (WebAudio)
- ✅ Progresso salvo localmente
- ✅ Funciona 100% offline
- ✅ Instalável como app

## Tecnologias

- Three.js (WebGL 3D)
- Vanilla JS (ES Modules)
- Service Worker + Web App Manifest
- WebAudio API
